# Fine-tuning

## 6. Fine-tune a task head

!!! info "Not yet implemented"

    Fine-tuning is not yet implemented in this package. The released task models
    (basecalling, demultiplexing, species, modifications) are published as trained
    weights; the fine-tuning code that produced them is being prepared for a later
    release.

See [Downstream tasks](../getting-started/tasks.md) for what the task models do.
